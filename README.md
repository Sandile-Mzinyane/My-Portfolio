# Personal Portfolio Website

A modern, responsive portfolio website built using **HTML**, **CSS**, and **JavaScript**. This project serves as my professional online presence, showcasing my background, technical skills, experience, and software development projects while demonstrating my understanding of core front-end web development concepts.

---

## About the Project

This portfolio was designed and developed from scratch to provide a clean, responsive, and user-friendly experience. It reflects my journey as an aspiring software developer and highlights the projects I've built while strengthening my understanding of fundamental web technologies.

The website includes sections that introduce who I am, outline my technical experience, and present selected projects with an intuitive and visually appealing interface.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Sandile-Mzinyane/My-Portfolio.git
```

### Navigate to the project

```bash
cd My-Portfolio
```

### Open the website

Open the `index.html` file in your preferred web browser.
